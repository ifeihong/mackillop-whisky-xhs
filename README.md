BORED WHISKY（年轻人的口袋威士忌）专属**小红书爆款图文生成器 v5.0**。融合 v2.0 设计感与 v4.0 数据逻辑，基于 **6 大内容模板 × 8 种视觉风格 × 8 种配色方案 × 8 种信息呈现方式**，一次输出 3:4 高端封面图 AI 生图提示词 + 小红书完整文案（标题 + 正文 + 话题标签）。适配 GPT Image2 / Seedream5.0 / Nano Banana Pro 等主流 AI 生图模型。

**v5.0 核心理念**：每张图既是完整可消费的内容，又有时尚设计感。基于 88 篇真实笔记数据分析，主标题缩略图强制可读、信息完整有价值、产品不孤立有场景。

**关键词**：小红书图文 / 小红书封面 / 小红书种草 / AI 生图提示词 / 小红书文案 / 威士忌营销 / 社交媒体内容生成 / 小红书爆款笔记

### 数据驱动原则

基于 88 篇真实笔记数据分析，v5.0 强制执行以下原则：

| 原则 | 数据依据 | 执行标准 |
|------|---------|---------|
| 主标题大字可读 | 缩略图 0.5 秒决定点击 | 主标题 ≥ 画面高度 12%，推荐 15-20% |
| 提问式/反差式标题 | CTR 可达 10-13% | 优先使用提问/反差/站队标题 |
| 信息有收藏价值 | 信息图/攻略/清单点赞最高 | 每张图承载 3-5 条完整信息 |
| 产品不孤立 | 有场景的图片完读率更高 | 搭配 2-5 个生活物件，有材质背景 |
| 钩子开头 | 禁止问候语式开头 | 开头必须是对话/独白/场景切入 |
| 每篇有 CTA | 互动引导提升评论率 | 提问/投票/@好友/挑战，6 种轮换 |
| 信息是完整句子 | 关键词/谜语无价值 | 每条 15-25 字完整句子 |
| 禁止伪装海报 | 电影票/门票/菜单广告感重 CTR 低 | 严禁此类形式 |

### 使用

**最简路径 — 直接对话：**
```
帮我生成一篇 BORED WHISKY 的露营主题图文
8月2日推荐一篇内容
```

**半自定义 — 指定方向：**
```
做一篇知识清单型，T3信息卡模板
用 T4 桌面搭配 + 杂志专栏风格，互动提问型
```

**追热点 — AI 自动推荐：**
```
结合最近热点做一篇
8月1日做什么好
```

### 注意事项

- 需配合外部 AI 生图模型使用（GPT Image2 / Nano Banana Pro / Seedream5.0 Pro）
- 需同时上传两张参考图：产品图（透明底 PNG）+ 品牌 LOGO
- 产品外观严格按参考图 1 还原，不脑补未展示部位
- 产品尺寸约成人手掌大小（15-18cm），与其他物体保持真实比例
- **严禁生成额外猴子/BAYC 图像，只保留产品瓶身自带 logo**
- 人物不露完整正脸，优先侧脸/背影/局部/道具遮挡/景深虚化
- **文案不出现具体容量数字（200ml/350ML），用"口袋装""小瓶装""手掌大小"替代**
- 场景限定简单日常（桌面/窗边/沙发），禁止复杂酒吧/露营地等容易出 AI 假感的场景
- 装饰元素不使用胶带/邮戳/邮票/条形码/半色调网点（缩略图下增加噪点降低清晰度）
